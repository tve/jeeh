## Example projects

- **`arduino/`** - using je JeeH library alongside the Arduino runtime
- **`blink/`** - a very simple LED blinker for a variety of boards
- **`ethernet/`** - driver for the F4/F7 built-in ethernet peripheral
- **`f429hy/`** - HAOYU STM32F429GI board w/ on-board RAM/NOR/NAND and 5" LCD
- **`i2c/`** - test code for I2C devices connected to a Nucleo-L432KC board
- **`sleep/`** - exploring low-power modes with a Nucleo-L432KC board
