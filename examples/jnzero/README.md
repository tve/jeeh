**Demos for the JeeNode Zero v4, using the STM32L052K8 and RFM69. **

- There's a 32 kHz crystal between PC14 and PC15, with 2x 12 pF to ground.
- Only USART2 TX (PA2) is connected to the Black Magic Probe connector.
- The RESET pin on the side header is connected to a push button.

### JNZ4 pins:

- PB3 SCLK RADIO
- PB4 MISO RADIO
- PB5 MOSI RADIO
- PA15 NSEL RADIO
- PB0 DIO0 RADIO
- PB1 DIO1 RADIO
- PB6 I2C1 SCL / USART1 TX
- PB7 I2C1 SDA / USART1 RX
- PA0 WKUP
- PA1 SENSOR POWER
- PA2 USART2 TX
- PA3 USART2 RX
- PA4 SPI1 NSEL
- PA5 SPI1 SCLK
- PA6 SPI1 MISO
- PA7 SPI1 MOSI
- PA8 LED
- PA9 USART1 TX
- PA10 USART1 RX
